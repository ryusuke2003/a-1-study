# プロジェクト管理

## 2026-08-29

### タックマンモデル

- タックマンモデルは、チームの発展を5段階で捉えるモデルである。順序は、**成立期（Forming）→ 動乱期（Storming）→ 安定期（Norming）→ 遂行期（Performing）→ 終結期（Adjourning）**である。
- **成立期**は、チームが作られた直後で、メンバーが目的や役割を探りながら関係を築き始める段階である。
- **動乱期**は、メンバーごとの考え方・価値観・意見の違いが明確になり、意見を主張し合い、対立や混乱が生じやすい段階である。画像の設問の正解は **エ**。
- **安定期**は、役割分担やルールが整い、メンバー間の協力関係が安定する段階である。
- **遂行期**は、チームが自律的に協働し、目標達成に向けて高い成果を出す段階である。
- **終結期**は、目標達成やプロジェクト終了に伴い、活動を完了・振り返り・解散する段階である。

### 見分け方

| 状態 | 段階 |
|---|---|
| 目的・役割を探り、関係を築き始める | 成立期 |
| 意見や価値観がぶつかり、主張・対立が表面化する | 動乱期 |
| ルールと役割が定まり、協力が安定する | 安定期 |
| 自律的に協働して成果を出す | 遂行期 |
| 活動を完了し、振り返りや解散を行う | 終結期 |

### プログラムマネジメント

- プログラムマネジメントは、事業目標・組織戦略の実現に向けて、相互に関連する複数のプロジェクトを一つのプログラムとして統合的に管理し、連携や相互作用から価値を高める考え方である。問23の正解は **ア**。
- 個々のプロジェクトをさらに細分化して管理することではない。
- **PMO（Project Management Office）**は、組織全体のプロジェクトマネジメントを支援し、標準化・能力・品質向上などを担う専門組織である。問23の **エ** はPMOの説明。

| 着眼点 | 用語 |
| --- | --- |
| 複数プロジェクトを統合し、戦略実現・価値向上を目指す | プログラムマネジメント |
| 組織全体のプロジェクト管理を支援する専門組織 | PMO |
