# システム開発技術

## 2026-08-29

### UML（Unified Modeling Language）

- UMLは、ソフトウェアシステムを視覚的にモデル化し、構造・振る舞い・利用者との関係などを共通の記法で表すための統一モデリング言語である。
- 要件定義や設計で、関係者間の認識を合わせ、システムの構造や動作を整理・伝達するために使う。
- UMLには、対象に応じてクラス図、オブジェクト図、アクティビティ図、シーケンス図、コンポーネント図、ユースケース図など複数の図がある。

### UML図の対象

- **オブジェクト図**は、ある時点に存在するオブジェクト（クラスのインスタンス）と、オブジェクト間のリンク・関係を表す。インスタンス間の関係を問う設問の答えはオブジェクト図である。
- **アクティビティ図**は、処理・活動の流れ、分岐、並行処理などを表す。オブジェクト間の静的な関係を表す図ではない。
- **コンポーネント図**は、ソフトウェアを構成するコンポーネントと、それらの依存関係・提供／要求インタフェースを表す。
- **ユースケース図**は、システムが提供する機能（ユースケース）と、利用者や外部システムなどのアクターとの関係を表す。

### 見分け方

| 問われる対象 | UML図 |
|---|---|
| インスタンス（オブジェクト）間の関係 | オブジェクト図 |
| 処理や活動の流れ | アクティビティ図 |
| ソフトウェア部品の構成・依存関係 | コンポーネント図 |
| 利用者とシステム機能の関係 | ユースケース図 |
