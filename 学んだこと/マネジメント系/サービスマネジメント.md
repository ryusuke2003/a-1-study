# サービスマネジメント

## 2026-08-29

### 問題管理（Problem Management）

- 問題管理は、インシデントの根本原因を特定し、恒久的な解決や再発防止につなげる活動である。画像の設問の正解は **ア：根本原因の特定**。
- インシデント管理がサービスを早期に復旧することを主眼とするのに対し、問題管理は、同一・類似のインシデントが繰り返されないよう原因を調査・管理する。
- サービス要求の優先度付けは、要求をどの順で処理するかを決める活動であり、根本原因の分析ではない。
- 変更要求の記録は、変更管理における要求の受付・記録に当たる。
- リリースの検証は、リリース・展開に関する活動である。

### 見分け方

| 活動 | 主な対象 |
|---|---|
| 問題管理 | 根本原因の特定、恒久対策、再発防止 |
| サービス要求管理 | 利用者からの要求の受付・処理・優先度付け |
| 変更管理 | 変更要求の記録・評価・承認・統制 |
| リリース管理 | リリースの準備・展開・検証 |

## 2026-09-10

### サービスレベル管理と関連活動の区別

- 令和6年度春期 高度試験 午前I 問20の正解は **エ**。
- **サービスレベル管理**は、サービス提供者と顧客が、提供するサービスの内容やサービスレベル目標を合意し、その達成状況を監視・報告・改善する活動である。サービス内容、可用性、応答時間などの合意事項は、**SLA（Service Level Agreement）**として文書化される。
- 資源の需要予測はキャパシティ管理、必要な資金の確保はサービスの予算・会計に関する活動、災害や障害からの復旧計画はITサービス継続管理に当たる。

#### 選択肢の判断

| 選択肢 | 判断 |
| --- | --- |
| ア 現在の資源を調整・最適化し、将来の資源要件を予測した計画を作成する | 誤り。必要な処理能力や資源を計画する**キャパシティ管理**の説明 |
| イ サービス提供に必要な予算に応じて、適切な資金を確保する | 誤り。サービスの予算・会計など、財務管理に関する活動 |
| ウ 災害・障害による事業中断時に、要求されたサービス機能を合意期間内に復旧できるよう、事業影響度と復旧優先順位を明確にする | 誤り。**ITサービス継続管理**の説明 |
| **エ 提供するサービス及びサービスレベル目標を決定し、顧客との間で合意文書を交わす** | **正しい。サービスレベル管理とSLAの説明** |

- 覚え方は、**顧客とのサービス水準の合意＝サービスレベル管理、合意文書＝SLA**。
