## 2026-09-07

### DX推進指標におけるITシステムの確認ポイント

- 経済産業省の**DX推進指標**は、企業がDXの現状や課題を自己診断し、経営者と関係者で認識を共有するための指標である。
- 令和6年度秋期 高度試験 午前I 問23の正解は **イ**。DXの基盤となるITシステムには、**環境変化へ迅速に対応し、求められるデリバリースピードで変更を届けられること**が求められる。

| 選択肢 | 判断 |
| --- | --- |
| ア 人材を育成・確保できているか | 人材・体制の話であり、この設問の「ITシステムに求められる要素」とは異なる |
| **イ 環境変化とデリバリースピードに対応できるか** | **正解** |
| ウ リアルタイム性より事後分析を重視するか | DXで一律に事後分析を優先するわけではない |
| エ 全体最適より個別最適を優先するか | 部門ごとの個別最適だけでは連携しにくくなるため不適切 |

#### 覚えるポイント

- **デリバリースピード**：必要な機能や変更を利用者へ届けるまでの速さ。
- **全体最適**：部門ごとにバラバラに最適化するのではなく、企業全体としてシステムやデータを連携しやすくする考え方。
- 試験では、**「変化に素早く対応」= DX基盤として適切**と判断できればよい。

## 2026-09-08

### DXを支える経営とITシステムの全体像

- DXは、データやデジタル技術を使って、環境・顧客・競争の変化に対応し、事業上の価値を継続的に生み出す取組として捉える。ITシステムだけを新しくすること自体が目的ではない。
- 体系的には、**経営の方向付け**、**組織横断の実行**、**ITシステムの適応力**の三層で考える。

| 層 | 問い | 重視すること |
| --- | --- | --- |
| 経営の方向付け | どの変化に対し、どの価値を生むか | ビジョン・戦略・優先順位 |
| 組織横断の実行 | 部門や人をまたいで実行できるか | 全体最適、関係者の認識共有、人材・体制 |
| ITシステムの適応力 | 必要な変更を安全かつ速く届けられるか | 連携性、変更容易性、求められるデリバリースピード、適切なデータ活用 |

- ITシステムに関する設問では、次の流れで判定する。

  1. 外部環境・顧客ニーズの変化をデータなどから捉える。
  2. 全社の目的に照らして、部門ごとで閉じずに必要な変更を決める。
  3. ITシステムが、その変更を求められる速さで利用者へ届ける。
  4. 結果を確認し、次の変化への対応へつなげる。
- したがって、個別最適を優先する、変化への対応を遅らせる、リアルタイム性又は事後分析のどちらかを常に一律に優先するといった考え方は、この流れに合わない。データ活用のタイミングは目的に応じて選ぶ。
- 人材育成・確保はDX推進には重要だが、ITシステムそのものの性質を問う設問では、組織・体制の層の論点である。
