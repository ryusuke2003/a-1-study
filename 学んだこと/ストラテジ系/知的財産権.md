# 知的財産権

## 2026-08-29

### ソフトウェア開発委託と著作者人格権不行使特約

- ソフトウェアの著作権を委託元へ移転する契約であっても、著作者人格権は著作者に一身専属し、譲渡できない。著作権（財産権）と著作者人格権は別の権利である。
- 著作者人格権には、公表権、氏名表示権、同一性保持権がある。例えば同一性保持権により、著作者は意に反する改変を受けない。
- そのため、委託先（及び実際の著作者）が「委託元に対して著作者人格権を行使しない」と合意する不行使特約を置くことがある。
- この特約の目的は、委託元が納品後のソフトウェアを、委託先の了解をその都度得ずに改修したり、他社へ改修を依頼したりできなくなることを防ぐことである。画像の設問の正解は **エ**。
- これは技術者倫理上の責任、委託元による開発者の雇用、又は不具合時の金銭補償を直接扱う条項ではない。

### 意匠法とGUI

- 意匠法は、物品・建築物・画像の**デザイン**を保護対象とする。独自のGUIは画像デザインに当たり得るため、問30の正解は **ア**。
- 意匠登録を受けるには、新規性や創作非容易性などの要件を満たす必要がある。独自であれば必ず登録・保護されるわけではない。
- 独自のアルゴリズム、通信プロトコル、ビジネスモデルは、いずれも「見た目のデザイン」そのものではないため、意匠法の保護対象ではない。技術的なアイデアとして特許法の保護対象となり得るかは、別途、発明の要件を満たすかで判断する。

| 対象 | この設問での整理 |
| --- | --- |
| GUIの画面デザイン | 意匠法の保護対象となり得る |
| アルゴリズム | デザインではない。技術的発明としての保護可能性は別判断 |
| 通信プロトコル | デザインではない。技術的発明としての保護可能性は別判断 |
| ビジネスモデル | デザインではない。技術的発明としての保護可能性は別判断 |

### 生成AIで作成した画像と著作権侵害

- AI生成物を公開・販売するなどして利用する場面の著作権侵害は、原則として人が作成したものと同様に判断する。既存著作物との**類似性**と**依拠性**が認められ、許諾や権利制限規定の適用がなければ、複製権・公衆送信権などの侵害になり得る。
- **類似性**は、AI生成物から既存著作物の創作的表現上の本質的な特徴を直接感じ取れるかという観点で判断する。**依拠性**は、既存著作物に基づいて作成したと認められるかという観点で判断する。
- したがって、AIで生成した画像が著作権で保護された既存画像と類似し、それを公開した場合は著作権侵害となる可能性がある。問30の正解は **イ**。

| 選択肢の主張 | 判断 |
| --- | --- |
| 著作物を学習データに含めれば、画像を生成するだけで常に侵害 | AI学習段階の著作物利用には著作権法30条の4が適用され得るため、学習に使ったという事実だけで常に侵害とはいえない。利用目的や権利者の利益を不当に害するかなどを個別に判断する。 |
| 既存の著作物と類似した生成画像を公開すると侵害になり得る | 類似性・依拠性があり、許諾や権利制限規定がなければ侵害となり得る。 |
| AIが自動生成した画像は著作物でないので、既存著作物の侵害も起きない | AI生成物自体が著作物として保護されるかと、他者の既存著作物を侵害するかは別問題である。 |
| 私的利用だけが認められ、商業利用なら必ず侵害 | 私的使用には権利制限規定があり得るが、商業利用もそれだけで直ちに侵害になるわけではない。類似性・依拠性、利用行為、許諾などで判断する。 |

## 2026-09-10

### 不正競争防止法におけるドメイン名の不正取得等

- 令和6年度春期 高度試験 午前I 問30の正解は **ウ**。
- 不正競争防止法では、**不正の利益を得る目的**又は**他人に損害を加える目的**で、他人の商品・サービスなどを示す表示と同一又は類似のドメイン名を取得・保有・使用する行為を、不正競争の一類型としている。
- 対象となる表示は、登録商標に限られない。したがって、商標権が設定されていない商品名でも、他人の商品を示す表示と類似するドメイン名を利用してコピー商品を販売し、不正に利益を得る行為は該当し得る。
- 一方、名称が偶然似ただけの場合や、自社の正当な事業のために利用する場合など、**不正の利益を得る目的又は他人に損害を加える目的がないもの**は、このドメイン名に関する類型には直ちに該当しない。

#### 選択肢の判断

| 選択肢 | 判断 |
| --- | --- |
| ア 競争関係にないB社が、偶然A社の社名に類似するドメイン名を取得した | 誤り。偶然の取得であり、不正の利益を得る目的又は他人に損害を加える目的が示されていない |
| イ ある地方だけで有名な和菓子に類似した商品名の飲料を、その和菓子が有名でない地方で販売して利益を得た | 誤り。この記述だけでは、周知表示について需要者の混同を生じさせる行為などに当たるとはいえず、ドメイン名の不正取得でもない |
| **ウ 商標権のない商品名を用いたドメイン名を取得し、その商品のコピー商品を販売して利益を得た** | **正しい。商標登録の有無にかかわらず、他人の商品表示に類似するドメイン名を不正利益目的で使用する行為は該当し得る** |
| エ 他社サービスと類似するが、自社サービスに適しており、正当な利益を得る目的のドメイン名を取得・利用した | 誤り。正当な自社事業目的であり、不正利益目的又は加害目的が認められない |

- 覚え方は、**類似ドメイン名だけでは足りず、「不正利益目的又は加害目的」が鍵。商標登録は必須条件ではない**。
