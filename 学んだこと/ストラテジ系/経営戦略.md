### PBP法（Payback Period Method：投資回収期間法）

- PBP法は、初期投資額を回収するまでに要する**期間の長さ**で投資案を評価する手法である。問25の正解は **ウ**。
- 回収期間が短いほど、資金を早く回収できる投資案と評価する。
- 通常のPBP法は、キャッシュフローの時間的価値（割引率）を考慮せず、投資回収後のキャッシュフローも評価に含めない。
- **NPV法**は将来キャッシュフローを割り引いて正味現在価値で評価し、**IRR法**はNPVがゼロになる割引率で評価する。両者は時間的価値を考慮する点でPBP法と異なる。

| 手法 | 主な評価基準 | 時間的価値 | 回収後のキャッシュフロー |
| --- | --- | --- | --- |
| PBP法 | 投資回収までの期間 | 通常は考慮しない | 通常は考慮しない |
| NPV法 | 正味現在価値 | 考慮する | 考慮する |
| IRR法 | NPVがゼロとなる割引率 | 考慮する | 考慮する |

### バランススコアカードと戦略マップ

- **バランススコアカード（BSC）**は、財務・顧客・内部ビジネスプロセス・学習と成長の四つの視点から、戦略を目標や指標へ展開して管理する手法である。
- **戦略マップ**は、この四つの視点を基に、課題・施策・目標の**因果関係**を可視化するもの。問26の正解は **イ**。
- 戦略マップでは一般に、学習と成長が内部ビジネスプロセスを改善し、顧客価値の向上を経て、財務成果へつながるという関係を示す。

| --- | --- |
| 二つの軸で市場における自社・製品の位置を表す | ポジショニングマップ |
| 市場の魅力度と自社の優位性で事業を分類する | GE／マッキンゼー・マトリックス |

### アンゾフの成長マトリクス

- アンゾフの成長マトリクスは、**市場**と**製品**をそれぞれ既存・新規に分け、成長戦略を四つに整理する枠組みである。
- **市場浸透戦略**は、既存市場に既存製品をより多く販売する戦略である。問27の正解は **イ**。特別価格などで既存地域の認知度や販売量を高める施策が当たる。
- 既存製品を新たな地域・顧客層へ販売するのは新市場開拓戦略である。新製品を既存顧客へ販売するのは新製品開発戦略、新市場へ新製品を投入するのは多角化戦略である。

| 市場 | 製品 | 戦略 |
| --- | --- | --- |
| 既存 | 既存 | 市場浸透戦略 |
| 既存 | 新規 | 新製品開発戦略 |
| 新規 | 既存 | 新市場開拓戦略 |
| 新規 | 新規 | 多角化戦略 |

## 2026-09-01

### GE／マッキンゼー・マトリックス

- GE／マッキンゼー・マトリックスは、多角化企業が複数の事業単位を比較し、どの事業へ経営資源を優先配分するかを検討するためのポートフォリオ分析手法である。GEとマッキンゼーが1970年代初めに開発したことから、**ナインボックス・マトリックス**とも呼ばれる。
- 縦軸は事業が属する**業界の魅力度**、横軸はその業界における**事業単位の競争力**である。それぞれを高・中・低の3段階で評価し、事業を3×3の9セルへ配置する。
- 業界の魅力度は、市場規模・成長性・収益性・競争状況・参入障壁など、外部環境に関する複数要因から評価する。事業単位の競争力は、市場地位、ブランド、コスト競争力、技術・販売力など、自社側の複数要因から評価する。単一指標だけで機械的に決めるものではない。
- 基本方針は、業界の魅力度と競争力が高い領域では**投資・成長**、中間領域では**選択的投資・収益確保**、両方が低い領域では**収穫・売却・撤退**を検討する。ただし、強い事業でも業界が魅力的でない場合と、魅力的な業界でも事業が弱い場合では課題が異なるため、セルだけでなく個別事情も判断する。

| 比較項目 | GE／マッキンゼー・マトリックス | BCGのPPM（成長率・市場占有率マトリックス） |
| --- | --- | --- |
| 形 | 3×3の9セル | 2×2の4象限 |
| 外部環境の軸 | 業界の魅力度を複数要因で評価 | 市場成長率 |
| 自社側の軸 | 事業単位の競争力を複数要因で評価 | 相対的市場シェア |
| 主な用途 | 事業間の投資優先順位を多面的に検討 | スター、金のなる木、問題児、負け犬に分類して資金配分を検討 |

### DX（Digital Transformation）

- **DX（Digital Transformation）**は、データやデジタル技術を活用して、業務プロセスだけでなく、製品・サービス・組織・ビジネスモデルそのものを変革し、競争上の優位性や新しい価値につなげていく考え方である。
- 単に紙の申請書をWebフォームに置き換える、既存システムをクラウドへ移す、といった**デジタル化だけで自動的にDXになるわけではない**。デジタル技術を使って仕事の進め方や顧客への価値提供のあり方まで変えることがポイントである。
- 例えば、紙の申請をWebフォームに変えるだけなら主にデジタル化だが、オンライン申請、データ連携、自動審査などを組み合わせ、審査時間を大幅に短縮してオンライン完結型の新しいサービスへ変えるなら、DXの例として捉えやすい。
- 試験向けには、**「DX = デジタル技術を活用して、業務・組織・製品・サービス・ビジネスモデルを変革すること」**と覚える。
- `DX` は `Digital Transformation` の略で、`Transformation` の `Trans` を `X` で表す慣用的な略し方に由来する。

### DX認定制度の認定基準

- **DX認定制度**は、デジタルガバナンス・コードに定める認定基準に基づき、DX推進の準備が整っている事業者を認定する制度である。
- 認定基準には、データ活用やデジタル技術の進化による社会・競争環境の変化を踏まえた**経営ビジョン及びビジネスモデルの方向性を公表**していることと、そのビジネスモデルを実現する方策として**DX戦略を公表**していることが含まれる。画像の設問の正解は **イ**。
- 認定時点でビジネスモデル革新などの成果目標を既に達成していることまでは求められない。DX認定は、成果の表彰ではなく、DXに向けた経営の方向性・戦略・体制などを整備し公表していることを評価する。
- **DX推進指標**は、経営者や社内関係者がDXの取組状況・課題の認識を共有するための自己診断指標であり、DX認定の全認定基準を置き換えるものではない。また、DX認定はデジタルガバナンス・コード3.0の全項目への対応を一律に求める制度ではなく、コードに示された認定基準に対して判断される。

| 選択肢 | 判断 |
| --- | --- |
| ア | 経営ビジョン・DX戦略の公表は必要だが、成果目標の既達成までは認定基準ではない。 |
| イ | 経営ビジョンとビジネスモデルの方向性、及びその実現のためのDX戦略を公表するため正しい。 |
| ウ | DX推進指標は自己診断ツールであり、中小企業が実施していることが認定基準そのものではない。 |
| エ | デジタルガバナンス・コード3.0の全項目への対応が、そのまま認定基準ではない。 |

### 売上高・利益から変動費を求める

- 売上高が変化しても**変動費率と固定費が変わらない**場合、利益の増減は限界利益の増減に等しい。`利益 = 売上高 − 変動費 − 固定費 = 売上高 × 限界利益率 − 固定費` と表せる。
- 売上高7,000万円で200万円の損失、売上高9,000万円で600万円の利益なので、売上高の増加は2,000万円、利益の増加は800万円である。したがって、`限界利益率 = 800 ÷ 2,000 = 0.4`、`変動費率 = 1 − 0.4 = 0.6` となる。
- 売上高8,000万円の変動費は、`8,000 × 0.6 = 4,800万円` である。問29の正解は **ウ**。
- 検算すると、固定費は `7,000 × 0.4 − (−200) = 3,000万円`、売上高8,000万円の利益は `8,000 × 0.4 − 3,000 = 200万円` となる。

### 経営戦略フレームワークの全体像

経営戦略系のフレームワークは、名前を個別暗記するより、**何を知りたいときに使うか**で分類すると見分けやすい。

| 分類 | 主なフレームワーク | 何をするか |
| --- | --- | --- |
| 環境分析 | 3C / SWOT / PEST / 5フォース | 自社を取り巻く市場・競争・外部環境を整理する |
| 自社の強み分析 | VRIO / バリューチェーン / コアコンピタンス | 自社の資源・活動・中核能力から競争優位の源泉を探す |
| 事業配分・成長戦略 | PPM / GE・マッキンゼー / アンゾフ / プロダクトライフサイクル | どの事業へ投資するか、どう成長するかを考える |
| マーケティング | STP / 4P / ポジショニングマップ | どの顧客を狙い、どのような価値・売り方で届けるかを考える |
| 戦略実行・管理 | BSC / 戦略マップ / KPI・KGI・CSF | 決めた戦略を目標・指標へ落とし込み、実行状況を管理する |

大きな流れは、**環境を見る → 自社の強みを知る → 事業・成長方針を決める → 顧客への届け方を決める → 指標で実行を管理する**である。必ずこの順に実施するという意味ではないが、試験で目的を見分けるための整理として有効である。

#### まず3分類を直感で区別する

特に混同しやすい最初の三つは、**「外を見る → 自分を見る → 何をするか決める」**と整理すると分かりやすい。

| 分類 | 直感的な問い | 役割 |
| --- | --- | --- |
| **環境分析** | **「外の世界、今どうなってる？」** | 市場、顧客、競合、社会、業界構造などを把握して、戦略を考えるための材料を集める |
| **自社の強み分析** | **「で、うちは何が強いの？」** | 自社の技術、ブランド、資源、活動、ノウハウなどから、他社に勝てる武器を見つける |
| **事業配分・成長戦略** | **「じゃあ、どこに力を入れてどう伸ばす？」** | 集めた情報を踏まえて、どの事業へ投資するか、どの市場・製品方向へ成長するかを決める |

例えばスマートフォンメーカーなら、環境分析で「AIスマホ市場が伸びている・競合が強い」と外部状況を把握し、自社の強み分析で「カメラ技術やブランド力が強い」と自社の武器を確認する。その上で、事業配分・成長戦略で「AIスマホ事業へ投資する」「新しい顧客層へ展開する」と意思決定するイメージである。

試験向けには、**環境分析＝材料集め、自社の強み分析＝武器確認、事業配分・成長戦略＝意思決定**と覚えると見分けやすい。

#### 1. 環境分析

- **3C**：`Customer（市場・顧客）`、`Competitor（競合）`、`Company（自社）`の三つから事業環境を整理する。問題文に「顧客・競合・自社」が並べば3Cを疑う。
- **SWOT**：内部環境を`Strength（強み）`・`Weakness（弱み）`、外部環境を`Opportunity（機会）`・`Threat（脅威）`に分ける。**内部＝強み・弱み、外部＝機会・脅威**が重要。
- **PEST**：企業では制御しにくいマクロ環境を`Political（政治）`、`Economic（経済）`、`Social（社会）`、`Technological（技術）`で分析する。法改正、景気、人口動態、技術革新などを見る。
- **5フォース（ファイブフォース分析）**：業界の競争構造を、既存企業間の競争、新規参入の脅威、代替品の脅威、買い手の交渉力、売り手の交渉力という五つの力から分析する。**業界がどれくらい競争の厳しい構造か**を見る手法である。

見分け方は、**3C＝登場人物、SWOT＝内外×良悪、PEST＝社会全体の外部環境、5フォース＝業界内の競争構造**。

#### 2. 自社の強み分析

- **VRIO**：自社の経営資源や能力を`Value（価値）`、`Rarity（希少性）`、`Imitability（模倣困難性）`、`Organization（組織）`で評価し、持続的な競争優位につながるかを見る。
- **バリューチェーン**：企業活動を、購買物流、製造、出荷物流、販売・マーケティング、サービスなどの主活動と、調達・技術開発・人事・全般管理などの支援活動に分け、**どの活動で価値やコスト優位が生まれているか**を分析する。
- **コアコンピタンス**：顧客へ価値を提供する上で中核となり、競合が容易にまねできない企業独自の能力・技術・ノウハウを指す。単なる一製品の強さではなく、複数の製品・事業にも活用できる中核能力として捉える。

見分け方は、**VRIO＝資源を4条件で評価、バリューチェーン＝活動の流れを分解、コアコンピタンス＝まねしにくい中核能力**。

#### 3. 事業配分・成長戦略

- **PPM（BCGマトリクス）**：`市場成長率 × 相対的市場シェア`で事業を、花形（Star）、金のなる木（Cash Cow）、問題児（Question Mark）、負け犬（Dog）に分類し、経営資源の配分を考える。**市場成長率・相対的市場シェア**が決定的なキーワード。
- **GE／マッキンゼー・マトリックス**：`業界の魅力度 × 事業の競争力`で3×3の9セルに分け、投資・選択的投資・収穫・撤退などを検討する。PPMよりも複数要因を使って多面的に評価する。
- **アンゾフの成長マトリクス**：`市場の既存・新規 × 製品の既存・新規`から、市場浸透、新製品開発、新市場開拓、多角化の四つの成長戦略を整理する。
- **プロダクトライフサイクル（PLC）**：製品・市場が`導入期 → 成長期 → 成熟期 → 衰退期`と推移するという考え方。段階によって売上、利益、競争状況や適切なマーケティング施策が変わる。

特に混同しやすいのは、**PPMとGE／マッキンゼーは「複数事業への資源配分」**、**アンゾフは「どの方向へ成長するか」**、**PLCは「製品が今どの段階か」**を見る点である。

#### 4. マーケティング

- **STP**：`Segmentation（市場細分化） → Targeting（狙う市場の選択） → Positioning（競合と比べた自社の位置付け）`の順に、誰へどの立ち位置で価値を提供するかを決める。
- **4P（マーケティングミックス）**：`Product（製品）`、`Price（価格）`、`Place（流通）`、`Promotion（販促）`の四つを組み合わせ、商品・サービスを市場へ届ける施策を具体化する。
- **ポジショニングマップ**：価格と品質など、顧客が重視する二つの軸で自社・競合の商品を配置し、市場での相対的位置や空いているポジションを可視化する。軸は市場成長率・シェアに固定されないため、PPMとは別物である。

流れとしては、**STPで「誰に、どんな立ち位置で売るか」を決め、4Pで「具体的にどう売るか」を決める**と理解するとよい。

#### 5. 戦略実行・管理

- **BSC（バランススコアカード）**：戦略を`財務`、`顧客`、`内部ビジネスプロセス`、`学習と成長`の四つの視点へ展開し、目標や指標で管理する。
- **戦略マップ**：BSCなどの戦略目標について、`学習と成長 → 内部プロセス → 顧客 → 財務`のような因果関係を可視化する。
- **KGI（Key Goal Indicator）**：最終的に達成したいゴールを測る成果指標。例は売上高、利益、契約数など。
- **CSF（Critical Success Factor）**：その目標を達成するために特に重要となる成功要因。日本語では重要成功要因。
- **KPI（Key Performance Indicator）**：CSFなどの進み具合を途中で測る重要業績評価指標。例は商談数、継続率、処理時間など。

試験向けには、**KGI＝最終ゴール、CSF＝成功の鍵、KPI＝途中経過を測る数字**と整理する。

## 2026-09-10

### 外部委託におけるコンティンジェンシープラン

- 令和6年度春期 高度試験 午前I 問25の正解は **エ**。
- **コンティンジェンシープラン（緊急時対応計画）**は、特定したリスクが実際に顕在化した場合に備えて、あらかじめ実行する対応、代替手段、連絡・判断手順などを決めておく計画である。
- 製造を外部委託する場合、部品調達の停止や委託先の操業停止などが起きたときに、代替調達先・代替委託先への切替えなど、事業を継続するための対応を事前に決めておくことが該当する。
- 発生確率を下げる予防策や、委託先を評価・選定する活動とは異なり、**リスクが起きた後にどう対処するか**が中心である。

#### 選択肢の判断

| 選択肢 | 判断 |
| --- | --- |
| ア 実績のある外注先を利用してリスクの発生確率を低減する | 誤り。リスクを起こりにくくする予防・軽減策であり、顕在化後の対応計画ではない |
| イ 製造品質が担保されていることを確認できるように委託先と契約する | 誤り。品質確保のための契約・予防的統制であり、緊急時の対応計画ではない |
| ウ 複数の会社の見積りを比較検討して委託先を選定する | 誤り。通常時の調達・委託先選定であり、リスク顕在化時の対応ではない |
| **エ 部品調達のリスクが顕在化したときに備え、対処するための計画を策定する** | **正しい。リスク発生時に実行するコンティンジェンシープランの説明** |

- 覚え方は、**リスクが起きないようにするのは予防策、起きたときに発動するのがコンティンジェンシープラン**。

- A1-0209（既知のリスクに備えるコンティンジェンシー予備費との関連）

## 2026-09-10

### ファイブフォース分析と他の分析手法の区別

- 令和6年度春期 高度試験 午前I 問26の正解は **エ：ファイブフォース分析**。
- **ファイブフォース分析**は、業界の競争構造と収益性に影響する力を、**新規参入の脅威、売り手（供給者）の交渉力、買い手の交渉力、代替品の脅威、既存企業間の競争**の五つに分けて分析する。
- 問題文に「新規参入」「供給者」「代替製品」「買い手」「既存競合」が現れたら、五つの競争要因を見るファイブフォース分析と判断する。

#### 選択肢の判断

| 選択肢 | 判断 |
| --- | --- |
| ア PEST分析 | 誤り。政治・経済・社会・技術というマクロ環境を分析する手法 |
| イ VRIO分析 | 誤り。自社の経営資源・能力を価値、希少性、模倣困難性、組織の四点で評価する手法 |
| ウ バリューチェーン分析 | 誤り。企業活動を主活動・支援活動に分け、価値やコスト優位の源泉を分析する手法 |
| **エ ファイブフォース分析** | **正しい。業界の競争状態・収益構造を五つの競争要因で分析する** |

- 覚え方は、**PEST＝社会全体、VRIO＝自社資源、バリューチェーン＝自社活動、5フォース＝業界の競争構造**。

## 2026-09-10

### フィージビリティスタディと関連手法の区別

- 令和6年度春期 高度試験 午前I 問27の正解は **ア**。
- **フィージビリティスタディ（実現可能性調査）**は、新規事業、海外進出、公共事業、情報システム導入などを本格的に実施・投資する前に、技術面、経済面、運用面などから実現可能性や採算性を調査・検証する活動である。
- 将来予測の意見収束に使うデルファイ法、自由なアイデア創出を行うブレーンストーミング、製品の市場投入から衰退までを見るプロダクトライフサイクルとは目的が異なる。

#### 選択肢の判断

| 選択肢 | 判断 |
| --- | --- |
| **ア 新規事業・海外進出、公共事業の採算性、情報システム導入手段などの実現性を調査・検証する投資前評価** | **正しい。フィージビリティスタディの説明** |
| イ 専門家が匿名で意見を出し、結果をフィードバックしながら反復して意見を収束させる | 誤り。将来予測などに使う**デルファイ法**の説明 |
| ウ 参加者が自由にアイデアを出し、発想の相乗効果から多数の案を生み出す | 誤り。集団発想法である**ブレーンストーミング**の説明 |
| エ 商品の市場投入から衰退までを、導入期・成長期・成熟期・衰退期で表す | 誤り。**プロダクトライフサイクル**の説明 |

- 覚え方は、**Feasibility＝実行・投資する前に「本当に実現できるか」を確かめる**。
