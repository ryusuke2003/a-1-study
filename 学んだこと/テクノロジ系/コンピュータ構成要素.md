# コンピュータ構成要素

## 2026-08-28

### VLIWによる命令レベル並列性

- VLIW（Very Long Instruction Word）は、同時に実行可能な複数の操作を、コンパイル時に一つの非常に長い複合命令へまとめる方式である。
- この問いの正解は **VLIW（エ）**。
- CISCとRISCは命令セット設計の分類、MIMDは並列コンピュータの命令・データ流分類であり、コンパイル時の複合命令化を指す名称ではない。

### プロセッサと命令セット設計

- **プロセッサ（CPU）**は、主記憶から命令を取り出し、解読して実行する、コンピュータの処理の中心となる装置である。命令の種類や実行の仕組みが、CPU設計の違いにつながる。
- **CISC（Complex Instruction Set Computer）**は、複雑な処理を行う命令を多数備えるCPU設計である。
- **RISC（Reduced Instruction Set Computer）**は、単純で基本的な命令を中心にして、命令実行を高速化しやすくするCPU設計である。
- **MIMD（Multiple Instruction, Multiple Data）**は、複数のプロセッサなどが、それぞれ異なる命令列で異なるデータを処理する並列処理方式である。
- CISC／RISC／VLIWは命令セットや命令の組み立て方に関する分類であるのに対し、MIMDは複数の処理装置へ命令とデータをどう割り当てるかに関する分類である。

## 2026-08-31

### NIC（Network Interface Card）

- NIC（ネットワークインタフェースカード）は、コンピュータを LAN などのネットワークへ接続するためのハードウェア（ネットワークアダプタ）である。Ethernet 用の有線 NIC や無線 LAN アダプタがある。
- OS やアプリケーションが扱うデータを、ネットワークで送受信できる信号・フレームへ変換し、ネットワークとの送受信を担う。マザーボードに内蔵されていることもある。
- Ethernet では NIC に MAC アドレスが割り当てられ、同一 LAN 内でフレームの送信元・宛先を識別するために使われる。MAC アドレスは IP アドレスとは役割が異なる。
- NIC は端末をネットワークへ接続するインタフェースであり、異なるネットワーク間でパケットを中継・経路選択するルータとは異なる。

### CPU処理時間とCPI・クロック周期

- CPUの処理時間は、基本的に **命令数 × CPI × クロック周期** で求める。
- **CPI（Cycles Per Instruction）** は、1命令を実行するのに平均何クロック必要かを表す。値が小さいほど、同じクロック周期なら高速である。
- クロック周期とクロック周波数は逆数の関係にあり、**クロック周期 = 1 ÷ クロック周波数** である。クロック周期が短いほど、クロック周波数は高い。
- 処理速度はクロック周期又はクロック周波数だけでは決まらず、命令数とCPIも含めて比較する必要がある。

問4では同じプログラムを実行するので、命令数は共通として比から消去できる。

| コンピュータ | クロック周期 | CPI | 1命令当たりの平均処理時間 |
| --- | ---: | ---: | ---: |
| A | 1ナノ秒 | 4.0 | 4.0 × 1 = 4ナノ秒 |
| B | 4ナノ秒 | 0.5 | 0.5 × 4 = 2ナノ秒 |

したがって、Aの処理時間 ÷ Bの処理時間は **4 ÷ 2 = 2** なので、正解は **ウ（2倍）** である。

CPIが0.5という値もあり得る。これはパイプライン処理やスーパースカラなどによって複数命令を並行して進め、平均すると1クロック当たり2命令を完了できることを表す。
