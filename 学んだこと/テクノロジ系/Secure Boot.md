# Secure Boot

## 2026-09-13

### Secure Boot

- **Secure Boot**は、UEFIがOS起動時に実行するブートローダなどのプログラムについてデジタル署名を検証し、信頼されていないプログラムの起動を防ぐ仕組みである。
- UEFI自身やBIOSがマルウェアに感染していないかをSecure Bootが検査する仕組みではない。UEFIの起動後、次に実行するブートローダなどを検証することで、OS起動までの信頼の連鎖を作る。
- 覚え方は、**Secure Boot = UEFIが、OS起動時に実行されるプログラムの署名を検証し、不正なプログラムの起動を防ぐ仕組み**。
