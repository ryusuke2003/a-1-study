## 2026-09-07

### コンパイラの処理順序と各解析の違い

- コンパイラの典型的な流れは、**字句解析 → 構文解析 → 意味解析 → 最適化 → コード生成**。
- 令和6年度秋期 高度試験 午前I 問7は「コード生成までに行う処理のうち最後」を聞いているので、正解は **ウ：最適化**。

| 処理 | 試験での見分け方 |
| --- | --- |
| **字句解析** | 文字列を識別子・予約語・数値・演算子などの**トークン**へ分ける |
| **構文解析** | トークンの並びが文法に従っているか確認する |
| **意味解析** | 型や変数の宣言など、意味上の整合性を確認する |
| **最適化** | 結果を変えずに、処理を効率化する |
| **コード生成** | 実行可能な目的コードへ変換する |

覚え方は、**「単語に切る → 文法を見る → 意味を見る → 効率化 → コードにする」**。
