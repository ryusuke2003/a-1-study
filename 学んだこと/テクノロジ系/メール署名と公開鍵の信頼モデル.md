# メール署名と公開鍵の信頼モデル

## 2026-09-07

### S/MIMEとDKIMは同じメールで併用できる

- S/MIMEとDKIMはどちらも電子署名を利用するが、署名の主体と目的が異なるため、同じメールで併用できる。
- 送信者がS/MIMEでメール内容へ署名した後、送信側メールサーバーが配送時にDKIM署名を付ける構成がある。受信側では、S/MIME署名とDKIM署名をそれぞれ別の観点から検証する。
- 「S/MIME署名をDKIMで丸ごと包んで署名する」というより、S/MIMEは主にMIMEの内容を個人・組織の証明書で保護し、DKIMは選択されたメールヘッダーと本文を送信ドメイン側で署名する、という別レイヤーの署名と考えると分かりやすい。
- S/MIMEは必要に応じて本文の暗号化も行えるが、DKIMはメール本文を秘匿するための暗号化方式ではない。

### PGP / OpenPGPとS/MIMEの公開鍵の信頼モデル

- PGP / OpenPGPとS/MIMEは、どちらもメールなどの暗号化・電子署名に利用できるが、公開鍵を「誰のものとして信用するか」という代表的な信頼モデルが異なる。
- PGP / OpenPGPでは、利用者同士が互いの公開鍵に署名して信頼関係をつなぐ **Web of Trust** が代表的である。ある公開鍵が本人のものだと自分で確認した利用者がその鍵へ署名し、その署名関係を手掛かりに信頼を判断する。
- S/MIMEでは、X.509証明書とPKIを用い、認証局（CA）が公開鍵と本人・メールアドレスなどの主体との対応を証明する方式が基本となる。
- したがって両者の重要な違いは、単に「暗号化できるか」「署名できるか」ではなく、**公開鍵と本人の対応を誰がどのように保証するか**にある。
- Web of TrustはPGP / OpenPGPで有名な代表的信頼モデルであり、PGP系の利用が常にその運用だけに限定されるという意味ではない。
