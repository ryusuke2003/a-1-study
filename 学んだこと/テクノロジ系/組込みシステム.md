# 組込みシステム

## 2026-08-28

### スイッチ入力、チャタリング、エッジ検出

- 機械式スイッチは押下・解放の瞬間に接点が細かくON/OFFする**チャタリング**を起こす。デバウンス（チャタリング除去）をしないと、一回の押下を複数回の操作として誤検出する。
- スイッチを周期的に読み、今回値を `a`、前回値を `b` とすると、現在値と前回値の組合せから状態変化を検出できる。
- 問題のように「放された状態が0、押された状態が1」のとき、`0 → 1` の押下は立上りエッジであり、論理式は **`a・\bar b`** となる。
- 逆に `1 → 0` の解放は立下りエッジであり、論理式は **`\bar a・b`** となる。
- `・` はAND、`+` はOR、上線はNOT（論理否定）を表す。
- デバウンスには、一定時間入力が安定してから確定する、複数回連続で同じ値なら確定する、変化後の短時間を無視する、といった方法がある。
- 実機には「押すと1」だけでなく、プルアップ回路などで「押すと0」となるアクティブLow入力もある。入力の極性が逆なら、押下のエッジも立下りとして判断する。

## 2026-09-03

### アクティブHigh入力とスイッチ操作の扱い

- **アクティブHigh**は、信号がHigh（論理値 `1`）のときに、その入力・機能が有効な状態であることを表す。例えば、押すと入力が `1` になるスイッチはアクティブHigh入力である。これは「Highを保つためにスイッチを押し続ける必要がある」という意味ではない。
- スイッチを押し続ける必要があるかは、アクティブHigh／Lowという**電気的な極性**ではなく、プログラムが入力をどう扱うかで決まる。入力が `1` の間だけモーターを動かす設計なら押下を維持するが、`0 → 1` の立上りエッジを一度だけ検出してLEDの点灯・消灯を切り替える設計なら、押下後に手を離しても状態を維持できる。
- アクティブLowは逆に、Low（論理値 `0`）を有効状態とする。アクティブHighとLowのどちらでも、連続状態を使うか、押下・解放のエッジを使うか、チャタリングを除去するかは、必要な操作仕様に応じて決める。

### 間欠動作の平均電流

- IoTセンサーノードなどでは、短時間だけ測定・送信して、残りの時間を低消費電力の待機状態にする**間欠動作**によって消費電力を抑える。
- 複数の動作状態があるときの平均電流は、各状態の電流を単純平均するのではなく、各状態の継続時間で重み付けして求める。

  `平均電流 = Σ（各状態の電流 × 継続時間）÷ 全体時間`

問7で待機時間を `t` 秒とする。単位をそろえると、動作電流は `10mA = 10,000μA`、動作時間は `10ms = 0.01秒` である。

`平均電流 = (10,000 × 0.01 + 0.1 × t) ÷ (0.01 + t)`

平均電流を1μA以下にする最短の待機時間は、平均電流がちょうど1μAとなる境界から求める。

```text
(100 + 0.1t) ÷ (0.01 + t) = 1
100 + 0.1t = 0.01 + t
99.99 = 0.9t
t = 111.1秒
```

したがって正解は **ウ（111.1秒）** である。動作時間はわずか10ミリ秒でも、動作時の電流が待機時の10万倍なので、平均を1μA以下にするには長い待機時間が必要になる。

- `電流 × 時間`は、その期間に流れる電気量に対応する。各状態の電気量を合計して全体時間で割ると平均電流になる。
- 平均電流を小さくするには、動作電流を下げる、動作時間を短くする、待機電流を下げる、又は待機時間を長くして動作の割合（デューティ比）を下げる方法がある。

#### m（ミリ）とμ（マイクロ）の単位換算

- `m`（ミリ）は基準単位の **10⁻³（1,000分の1）**、`μ`（マイクロ）は **10⁻⁶（100万分の1）** を表すSI接頭語である。
- `10⁻³ ÷ 10⁻⁶ = 10³` なので、**1m単位 = 1,000μ単位**である。この関係は電流だけでなく、秒、メートル、グラムなど同じ基準単位に付く場合にも成り立つ。
- 大きい単位のmから小さい単位のμへ直すときは1,000倍し、μからmへ直すときは1,000で割る。

```text
1mA = 1,000μA
10mA = 10,000μA
0.1μA = 0.0001mA

1ms = 1,000μs
```

- 接頭語は大文字と小文字を区別する。小文字の`m`はミリ（10⁻³）だが、大文字の`M`はメガ（10⁶）である。
