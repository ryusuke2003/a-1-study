# 多元接続と媒体アクセス制御

## 2026-09-12

### 多元接続方式と媒体アクセス制御の違い

- **TDMA／FDMA／CDMA／OFDMA**は、複数の端末が通信資源を共有するときに、**その資源をどう分けるか**という多元接続方式として整理する。
  - **TDMA（Time Division Multiple Access）**：時間をタイムスロットに分ける。
  - **FDMA（Frequency Division Multiple Access）**：周波数帯を分ける。
  - **CDMA（Code Division Multiple Access）**：端末ごとに異なる符号を使って区別する。
  - **OFDMA（Orthogonal Frequency Division Multiple Access）**：直交する多数のサブキャリアを複数端末へ割り当て、周波数資源を細かく共有する。
- 一方、**CSMA/CD／CSMA/CA**は、共有媒体へ**いつアクセスして送信を始めるか**を制御する方式として整理する。
  - **CSMA/CD（Carrier Sense Multiple Access with Collision Detection）**：媒体を監視して空いていれば送信し、衝突を検出したら送信を中止して待機後に再送する。共有型・半二重Ethernetで使われた。
  - **CSMA/CA（Carrier Sense Multiple Access with Collision Avoidance）**：媒体を監視し、ランダムな待機などによって衝突をできるだけ避けて送信する。Wi-Fiで使われる。

覚え方は、**`TDMA / FDMA / CDMA / OFDMA = 通信資源をどう分けるか`、`CSMA/CD / CSMA/CA = 共有媒体をいつ使うか`**。

### Wi-Fi 6におけるOFDMAとCSMA/CA

- **Wi-Fi 6（IEEE 802.11ax）**ではOFDMAを利用し、1つの無線チャネルを細かい周波数資源に分けて複数端末へ割り当てることで、同じ送信機会の中で複数端末を効率よく収容できる。
- OFDMAで端末ごとの資源を割り当てても、**無線チャネル全体がそのAPだけの専有物になるわけではない**。同じ周辺で同じチャネルを使う別のAPや端末と競合する可能性がある。
- そのため、まずCSMA/CAで共有チャネルを利用できるタイミングを調整し、送信機会を得た後にOFDMAで周波数資源を複数端末へ割り当てる、と二段階で考えると分かりやすい。

```text
CSMA/CA
  ↓
共有チャネルを「今使ってよいか」を調整
  ↓
送信機会を得る
  ↓
OFDMA
  ↓
その送信機会の中で周波数資源を複数端末へ割り当てる
```

#### イメージ

- **CSMA/CA = 道路に入る順番を決める**
- **OFDMA = 道路に入った後、どの車線を誰が使うかを決める**

この二つは競合する仕組みではなく、役割が異なるため同時に使える。
