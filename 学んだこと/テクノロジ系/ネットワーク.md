# ネットワーク

## 2026-09-01

### IEEE 802.1XとRADIUS

- IEEE 802.1Xは、有線LANや無線LANで、認証・認可済みの端末だけにネットワーク接続を許可するポートベースのネットワークアクセス制御である。
- 主体は、接続を求める端末の**サプリカント**、スイッチやアクセスポイントなど接続を制御する**オーセンティケータ**、認証を判定する**認証サーバー**である。
- サプリカントとオーセンティケータの間ではEAPOL（EAP over LAN）が使われる。オーセンティケータと認証サーバーの間では、RADIUSでEAPメッセージを中継する構成が一般的である。
- RADIUSは、NAS（Network Access Server）と認証サーバーの間で認証・認可・アカウンティング（AAA）の情報を運ぶプロトコルである。802.1Xのアクセス制御そのものではなく、その認証サーバー連携でよく使われる。

### STPとMSTP

- STP（Spanning Tree Protocol）は、レイヤ2ネットワークの冗長経路によるループを防ぐため、論理的に木構造を作り、不要なポートをブロックするプロトコルである。
- STPはルートブリッジを選出し、各セグメントで転送するポートを決める。障害時にはトポロジを再計算し、ブロックしていた冗長経路を利用できるようにする。
- MSTP（Multiple Spanning Tree Protocol）は、複数のVLANを少数のスパニングツリーインスタンスへ対応付ける。VLANごとに異なる経路を使わせることで負荷分散しつつ、インスタンス数を抑えられる。
