# ネットワーク

## 2026-09-01

### IEEE 802.1XとRADIUS

- IEEE 802.1Xは、有線LANや無線LANで、認証・認可済みの端末だけにネットワーク接続を許可するポートベースのネットワークアクセス制御である。
- 主体は、接続を求める端末の**サプリカント**、スイッチやアクセスポイントなど接続を制御する**オーセンティケータ**、認証を判定する**認証サーバー**である。
- サプリカントとオーセンティケータの間ではEAPOL（EAP over LAN）が使われる。オーセンティケータと認証サーバーの間では、RADIUSでEAPメッセージを中継する構成が一般的である。
- RADIUSは、NAS（Network Access Server）と認証サーバーの間で認証・認可・アカウンティング（AAA）の情報を運ぶプロトコルである。802.1Xのアクセス制御そのものではなく、その認証サーバー連携でよく使われる。

## 2026-09-02

### NAS（Network Access Server）と家庭・組織の802.1X認証

- **NAS（Network Access Server）**は、端末がネットワークへ接続するときの入口となり、利用者・端末へアクセスサービスを提供する装置である。RADIUSから見ればNASは**RADIUSクライアント**であり、認証情報を認証サーバーへ渡し、許可・拒否や認可情報の応答に従って接続を制御する。
- IEEE 802.1Xの用語では、NASは**オーセンティケータ（Authenticator）**に当たる。無線LANではアクセスポイント、有線LANではLANスイッチ、リモートアクセスではVPN装置などがこの役割を担う。

| 主体 | 802.1Xでの役割 | 例 |
| --- | --- | --- |
| サプリカント（Supplicant） | 接続を求め、認証情報を提示する | PC、スマートフォン |
| NAS／オーセンティケータ | 接続を一時的に制限し、認証を要求・中継して結果に従う | 無線AP、LANスイッチ、VPN装置 |
| 認証サーバー | 資格情報を検証し、許可・拒否や認可情報を返す | RADIUSサーバー |

- 通信の基本的な流れは、`端末（Supplicant） ─ EAPOL ─ NAS／Authenticator ─ RADIUS ─ 認証サーバー` である。NASは認証の最終判定を自ら行うのではなく、端末と認証サーバーの間を中継し、結果を接続制御へ反映する。
- 一般家庭のWi-Fiルーターも無線APとして端末を接続させるが、通常は**WPA2/WPA3-Personal**の共有パスワードで認証する。この構成ではRADIUSサーバーを置かないため、802.1XにおけるNAS／RADIUSクライアントの役割は通常使わない。
- 組織では、**WPA2/WPA3-Enterprise**と802.1Xを組み合わせ、利用者・端末ごとにIDや証明書で認証する。退職・異動時に本人だけを停止できる、共有パスワードを全員分変更せずに済む、認証結果に応じてVLANやアクセス権を分けられる、といった利点がある。
- ただし802.1Xには、RADIUSサーバーの運用、アカウント・証明書の配布と失効管理、無線AP／スイッチの設定が必要である。少人数の家庭では共有パスワード方式で足りることが多く、追加の管理コストに見合いにくい。

### STPとMSTP

- STP（Spanning Tree Protocol）は、レイヤ2ネットワークの冗長経路によるループを防ぐため、論理的に木構造を作り、不要なポートをブロックするプロトコルである。
- STPはルートブリッジを選出し、各セグメントで転送するポートを決める。障害時にはトポロジを再計算し、ブロックしていた冗長経路を利用できるようにする。
- MSTP（Multiple Spanning Tree Protocol）は、複数のVLANを少数のスパニングツリーインスタンスへ対応付ける。VLANごとに異なる経路を使わせることで負荷分散しつつ、インスタンス数を抑えられる。

### VRRPとNAT

- **VRRP（Virtual Router Redundancy Protocol）**は、LAN内のデフォルトゲートウェイを冗長化するプロトコルである。複数のルーターで一つの**仮想IPアドレス**を共有し、端末はその仮想IPをデフォルトゲートウェイとして設定する。
- VRRPルーターのうち、現在パケット転送を担当する機器を**Master**、待機して障害時に引き継ぐ機器を**Backup**という。Masterが利用不能になると、Backupの一台がMasterへ切り替わるため、端末側でデフォルトゲートウェイの設定を変更せずに通信を継続しやすい。
- VRRPが解消するのは、単一のデフォルトゲートウェイが停止すると外部ネットワークへ出られなくなる**単一障害点**である。IPアドレスを変換したり、通信経路を負荷分散したりする仕組みそのものではない。
- **NAT（Network Address Translation）**は、ルーターなどの境界装置がパケットのIPアドレスを書き換える技術である。代表的には、内部のプライベートIPアドレスと外部で使うグローバルIPアドレスを対応付け、内部ネットワークを外部ネットワークへ接続する。
- **NAPT（Network Address Port Translation）**は、IPアドレスに加えてTCP/UDPのポート番号も変換する方式である。多くの内部端末を一つのグローバルIPアドレスで外部通信させる家庭用ルーターの「NAT」は、実際にはNAPTを含む構成であることが多い。

| 用語 | 解決する課題 | 主な動作 | 端末から見えるもの |
| --- | --- | --- | --- |
| VRRP | デフォルトゲートウェイの単一障害点 | Master障害時にBackupが仮想ルーターの転送を引き継ぐ | 同じ仮想IPのデフォルトゲートウェイ |
| NAT | 内部・外部で異なるIPアドレス空間を接続する | パケットの送信元・宛先IPアドレスを変換する | 通信時に境界装置でアドレスが変換される |
| NAPT | 少数のグローバルIPを複数端末で共有する | IPアドレスとポート番号を変換する | 多数端末が一つのグローバルIPを共有できる |
