# マルチメディア

## 2026-09-06

### SVGと画像形式の違い

- **SVG（Scalable Vector Graphics）**は、矩形、円、直線、文字列などの図形オブジェクトをXMLで記述する、W3C仕様のベクター画像形式である。Webブラウザーで表示でき、Webページ上の図形描画にも利用できる。問8の正解は **ウ**。
- ベクター画像は、画素そのものではなく座標・線・曲線・図形などの情報で表現する。そのため、拡大・縮小しても基本的に輪郭が粗くなりにくく、ロゴ・アイコン・図・グラフなどに向く。
- SVGはXMLベースなので、図形や文字を要素として記述できる。ブラウザー上ではDOMとして扱え、CSSによる見た目の変更やJavaScriptによる操作・アニメーションにも利用できる。

### PNG

- **PNG（Portable Network Graphics）**は、画素の集まりで画像を表すラスター画像形式である。
- **可逆圧縮**を使うため、保存時に元の画素情報を失わない。文字、線、UI、スクリーンショット、ロゴなど、輪郭をくっきり残したい画像に向く。
- アルファチャンネルによる**透過**を扱えるので、背景を透明にしたWeb素材にもよく使われる。
- Webブラウザーで広く扱える一方、写真のように色の変化が非常に多い画像ではJPEGなどよりファイルサイズが大きくなることがある。
- PNGはSVGと違ってラスター画像なので、元画像の解像度を超えて大きく拡大すると画素が目立ち、輪郭が粗くなる。

### TIFF

- **TIFF（Tagged Image File Format）**は、主に高品質なラスター画像を保存するための画像形式である。
- 非圧縮や可逆圧縮など複数の保存方法を扱え、高解像度・高い色深度などを保持しやすいため、スキャン原稿、印刷、出版、画像編集の中間データなどで使われる。
- 画質や保存情報を重視する用途に向く反面、ファイルサイズは大きくなりやすく、一般的なWebページで直接表示する画像形式としてはPNGほど広く使われない。
- TIFFもSVGのようにXMLで図形オブジェクトを記述する形式ではなく、基本的には画素ベースの画像を格納する形式である。

### PNG・TIFF・SVGの区別

| 形式 | 主な表現 | 圧縮・特徴 | 主な用途 | Webとの相性 |
|---|---|---|---|---|
| PNG | ラスター | 可逆圧縮、透過対応 | スクリーンショット、UI、ロゴ、Web画像 | 高い |
| TIFF | 主にラスター | 非圧縮・可逆圧縮など、高品質保存に向く | スキャン、印刷、出版、保存・編集 | 一般的なWeb表示には不向き |
| SVG | ベクター | XMLで図形を記述、拡大縮小に強い | アイコン、ロゴ、図、グラフ、Web描画 | 高い |

試験では、**PNG＝Web向けのラスター画像・可逆圧縮・透過、TIFF＝高品質保存・印刷・スキャン向け、SVG＝XMLベースのベクター画像**という軸で区別するとよい。

### W3C

- **W3C（World Wide Web Consortium）**は、Web技術の相互運用性を高めるため、Webに関する仕様・標準化を進める国際的な団体である。
- HTMLやCSS、SVG、Webアクセシビリティ関連など、Webで共通して利用される技術の仕様策定に関わっている。
- 試験では、細かな組織構造よりも、**「Web技術の標準ルールを策定・標準化する団体」**という役割を押さえる。
- 「W3Cで仕様が定義され、XML形式で矩形・円・直線・文字列などを記述できる画像形式」と問われたら、SVGを結び付ける。

### OpenGLとの違い

- **OpenGL**は2D・3Dグラフィックスを描画するためのAPIであり、PNG・TIFF・SVGのような画像ファイルフォーマットではない。
- したがって、「画像フォーマットはどれか」という問題では、OpenGLを画像形式として選ばないようにする。

### ビットマップフォントとアウトラインフォント

- 令和6年度春期 高度試験 午前I 問8の正解は **エ：文字を任意の倍率に拡大して表示する場合**。
- **ビットマップフォント**は、文字の形を画素の集まりとしてサイズごとに表現する。用意されたサイズではそのまま表示できるが、大きく拡大すると画素が目立ち、輪郭がぎざぎざになりやすい。
- **アウトラインフォント**は、文字の輪郭を直線や曲線などの数式・座標情報で表現する。表示時に指定サイズへ合わせて画素へ変換するため、拡大・縮小しても輪郭を滑らかに保ちやすい。

| 比較 | ビットマップフォント | アウトラインフォント |
| --- | --- | --- |
| 字形の表現 | 画素のパターン | 輪郭の線・曲線 |
| 拡大・縮小 | 元のサイズを超えると粗くなりやすい | 任意の大きさへ拡大・縮小しやすい |
| 表示 | 用意された画素を使う | 輪郭から表示用の画素を生成する |

#### 選択肢の判断

| 選択肢 | 判断 |
| --- | --- |
| ア 英数字だけでなく漢字も表示する | 誤り。表示できる文字種は収録されている字形によるので、アウトライン方式を選ぶ決め手ではない |
| イ 各文字の幅を一定にして表示する | 誤り。固定幅か可変幅かという文字幅の設計であり、ビットマップかアウトラインかとは別の軸 |
| ウ 画面上にできるだけ高速に表示する | 誤り。この設問でアウトラインフォントを選ぶ代表的な理由ではない。輪郭から表示用画素を生成する処理も必要になる |
| **エ 文字を任意の倍率に拡大して表示する** | **正しい。輪郭情報から指定サイズの字形を生成できる** |

- 覚え方は、**ビットマップ＝点で保存、アウトライン＝輪郭で保存**。拡大・縮小への強さを問われたらアウトラインフォントを選ぶ。
