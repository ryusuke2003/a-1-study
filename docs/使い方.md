# 使い方

日常操作はチャットで行う。`skills/a1-adaptive-review/SKILL.md` が、内容整理と関連補強問題の判断を担当する。`scripts/a1_review.py` は Markdown のカード状態、復習候補、採点結果を一貫して更新する補助コマンドである。

## 学んだことを登録する

チャットで学んだ内容を送る。AIが分野ノートへ整理し、最小知識単位に分けてカードを作る。カードの作成は次の形式で行える。

```bash
python3 scripts/a1_review.py add-card \
  --domain 'テクノロジ系 / ネットワーク' \
  --title 'TCPの3ウェイハンドシェイク' \
  --point '接続確立時のSYN、SYN/ACK、ACKの役割と順序を区別できる。' \
  --source '../../学んだこと/テクノロジ系/ネットワーク.md' \
  --prompt 'TCP接続確立の手順として最も適切なものを選ぶ。'
```

新しいカードの次回復習日は、JST（午前5時切替）の当日になる。登録だけでは問題Sessionを作らない。

## 復習問題を作る

チャットで「今日の復習問題を作って」と依頼する。AIは次のコマンドで候補を確認し、Skillの条件に従って5択問題を作る。

```bash
python3 scripts/a1_review.py candidates --count 5
```

カードと同じ分野だけに絞る場合は `--domain` を使う。出題Sessionは [問題・採点形式](../skills/a1-adaptive-review/references/問題・採点形式.md) に従い、解答キーは `学習記録/復習問題/解答/` に分けて保存する。

## 採点する

問題Sessionで A〜E のどれか一つをチェックした後、チャットで「採点して」と依頼する。AIは次を実行する。

```bash
python3 scripts/a1_review.py grade \
  --session '学習記録/復習問題/YYYY-MM-DD.md' \
  --key '学習記録/復習問題/解答/YYYY-MM-DD.md'
```

正答なら復習段階を一つ進め、誤答・`E. わかりません`・未選択・複数選択なら段階0に戻して翌日を次回復習日にする。採点後は、Session、カード一覧、分野別状況、学習履歴が更新される。

## 状況を見る

```bash
python3 scripts/a1_review.py candidates --count 10
python3 scripts/a1_review.py rebuild
```

前者は優先順位付きの出題候補、後者はカード一覧と分野別状況の再生成である。
