# セキスペ A-1 適応復習ノート

情報処理安全確保支援士試験の A-1 問題（旧・午前 I）向けに、**自分で学んだ内容を忘れないための復習リポジトリ**です。

このリポジトリは、試験範囲から自動的に新しい問題を網羅出題するものではありません。学習者がチャットに書いたメモ・理解・疑問を整理して蓄積し、その内容と、そこから自然につながる A-1 の重要知識を忘却曲線に沿って「4択＋わかりません」の5択問題で再確認します。

日々の学習操作に必要な判断・保存形式は、リポジトリ内の [A-1 適応復習 Skill](skills/a1-adaptive-review/SKILL.md) にまとめています。

カード管理と問題作成はチャットで行い、復習候補は未採点Sessionのカードを除外した後、排他的な「期限到来70%・期限前の弱点20%・未復習／近日期限10%」の選出枠を基準に抽出します。近日期限は既定3日以内です。期限枠にも誤答は含まれるので、誤答カード全体を20%に制限する意味ではありません。候補不足時は対象内で補充し、目標配分・実配分・不足数を分けて表示します。採点時は別の専用スクリプトが全問の採点欄、カード、監査集計を一括更新します。不正解・不明だった問題の問題文・模範解答・解説は、採点日の `学習記録/間違えた問題/` だけに保存します。通常の問題Sessionの採点欄には解説を追記しません。

## 予定している使い方

1. 学習者が、他の教材・講義・過去問などで学んだことを自由な文章で入力する
2. 入力内容を A-1 の分野別ノートと復習カードへ整理する
3. 「今日の復習問題を作って」と依頼する
4. 期限が近い／過ぎたカードに加え、登録内容に関連する重要知識も少数の「4択＋わかりません」の問題にして出題する
5. 回答後に採点し、結果に応じて次回復習日を更新する

学習日の切替は JST 午前 5 時です。00:00〜04:59 に行った学習は前日扱いにします。

## 設計上の原則

- 学習内容の正本は、人が読めて編集できる Markdown とする
- 学習者の入力を起点にし、登録時に直接つながる周辺知識を補い、出題時に必要範囲を再確認する
- メモの整理と、想起練習用の復習カードを分けて管理する
- 正答でも長期放置せず、間隔を広げながら再出題する
- 誤答・曖昧な回答は早めに再出題し、必要に応じて元メモを補う
- 学習者が明示的に問題作成を依頼するまで、問題は作成しない

## 記録の正本

- カードの現在状態は `復習カード/カード一覧.md`
- 出題内容と採点履歴は `学習記録/復習問題/YYYY-MM-DD.md` の各Session
- 不正解・不明の問題文、模範解答、選択肢別解説は `学習記録/間違えた問題/YYYY-MM-DD.md`

重複して内容がずれるのを防ぐため、集約用の `学習記録/学習履歴.md` は正本として使用しません。

## Skillの読み分けと品質検査

`AGENTS.md` → `skills/a1-adaptive-review/SKILL.md` を入口に、登録・出題・採点で必要な参照文書だけを読む構成です。スクリプトの実行にソース全文の読み込みは不要です。既存の8列カード、採点間隔、Markdown正本は変更していません。

出題では、登録範囲を守りながら問い方を変え、誤答肢のもっともらしさと情報量をそろえます。正解位置の私用配置表と、公開前の構造検査を用意しています。詳しくは [出題手順](skills/a1-adaptive-review/references/出題手順.md) を参照してください。チェック成功は、知識の正確さや学習効果の保証ではありません。

Python 3.10以上の標準ライブラリで実行します。

```bash
python3 -m unittest discover -s tests -v
python3 skills/a1-adaptive-review/scripts/verify_review_sessions.py
```

テストは一時ディレクトリの合成データを使い、実際の学習記録を変更しません。2行目は実リポジトリ全体の既存履歴監査です。

## 復習候補の抽出

```bash
python3 skills/a1-adaptive-review/scripts/select_review_cards.py --count 20 --format json
python3 skills/a1-adaptive-review/scripts/select_review_cards.py --count 30 --on 2026-09-06 --near-days 3
```

未採点は回答チェック済みでも除外します。期間外の復習カードで不足を埋めず、0件なら既存Sessionや学びの登録を案内します。枠の詳細、他のリポジトリを指定する方法、JSON出力は [出題手順](skills/a1-adaptive-review/references/出題手順.md) を参照してください。

`actual_buckets` は補充後もカード本来の選出枠を示し、以前の `backfill` キーは使いません。補充数は `backfilled_count`、各カードの補充理由は `selection_reason` に分離しています。独自のJSON利用処理がある場合はこの変更に合わせてください。

指示文書のサイズを任意の基準コミットと比較できます。基準版が作業別参照方式かどうかを自動判定します。

```bash
python3 scripts/measure_skill_context.py --base-ref c6253c43cff6d60ef18259335088e3b2231495b5
```

値は指示文書のUTF-8バイト数・文字数で、実際のトークン数・応答時間・学習効果ではありません。

## 復習状況を確認する

```bash
python3 skills/a1-adaptive-review/scripts/study_status.py
python3 skills/a1-adaptive-review/scripts/study_status.py --on 2026-09-06 --days 7 --format json
```

期限超過・当日期限・未採点・未復習・直近誤答/不明を、全体と分野別に集計します。`ready_due` は未採点Sessionに入っているカードを除いた期限到来数です。日付表は保存済みの `Next Review` を数えるだけで、将来の正答率や学習量の予測ではありません。弱点・未復習・未採点は期限の分類と重複します。これは現在状態の集計で、全履歴の正答率や定着率ではありません。問題生成・カード更新・新たな集約ファイルの作成は行いません。別の作業コピーは `--root` で指定します。

## 採点の安全性と自動検査

採点下書き作成後に問題・回答・対象カードが変わった場合や、出題時のStageが現在状態と違う場合は、更新せずエラーにします。原因を確認して再prepareしてください。別日の同じSession/Q番号は別の誤答記録として扱います。

実採点と清掃の同時書き込みは `.a1-grading.lock` で防ぎます。異常終了で残ったロックは、他の処理が停止し記録が整合していることを確認してから削除します。手編集・別の作業コピー・停電まで保証するロックやトランザクションではありません。下書きはリポジトリ外の一時ファイルへ保存し、処理後に削除してください。

GitHub Actionsでは、PRとmainへの更新時にPython 3.10/3.12のテスト、実学習履歴の読み取り専用監査、状況集計を実行します。接続権限は `contents: read` のみとし、ActionはコミットSHAで固定しています。ローカルの履歴監査は次でも実行できます。

```bash
python3 skills/a1-adaptive-review/scripts/verify_review_sessions.py --root /path/to/a-1-study
```

検査は知識内容の正確さや学習効果を保証しません。記録の不整合が見つかった場合は原因を確認し、過去の回答・採点結果を自動修正せずに対処します。
