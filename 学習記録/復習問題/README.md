# 復習問題

問題Sessionを日付単位で保存します。回答前のSession本文には正解を書きません。採点時は `skills/a1-adaptive-review/scripts/grade_review_session.py` が対象Sessionの全問へ `Score`、`Result`、`Next Review` を一括追記し、通常の問題Sessionには正誤・不明を問わず解説を追記しません。

不正解または不明だった問題の問題文、模範解答、A〜Dの選択肢別解説は、採点日の `学習記録/間違った問題/YYYY-MM-DD.md` に保存します。出題内容と採点結果の履歴は各Session自体を正本とします。
