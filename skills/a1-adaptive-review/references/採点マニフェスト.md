# 採点マニフェスト

採点はリポジトリ直下でSessionごとに次の順で行い、[採点・誤答形式](採点・誤答形式.md) に従う。複数Sessionが回答済みなら、学習者が限定しない限り各Sessionを対象にする。20問は出題既定値にすぎず、30問・49問以上も全問を一回のapplyに渡す。

AIは正解記号・結果と、不正解／不明のA〜D全解説だけを判断する。選択読取り、採点欄、復習期限、カード状態、監査、誤答記録は手編集しない。スクリプトを実行できない場合も部分採点で完了扱いにせず、原因を直す。

## 復習段階

正解したA〜Dは想起できた正答として段階を一つ進める。不正解、E、未選択は段階0に戻して翌日期限とし、複数選択は適用を止める。正答の間隔は3・7・14・30・60日、以降は概ね倍にする。初期段階0は当日または翌日を目安とする。一度の正答で長期定着と見なさない。通常Sessionには解説を付けず、不正解／不明のみ誤答記録にA〜D別の具体的解説を保存する。

## 1. JSON下書きを生成する

```bash
python3 skills/a1-adaptive-review/scripts/grade_review_session.py prepare \
  学習記録/復習問題/YYYY-MM-DD.md \
  --session N \
  --graded-on YYYY-MM-DD \
  --output /tmp/a1-grade-YYYY-MM-DD-session-N.json
```

`prepare` は問題番号、選択状態、Card ID、カード要点、問題文、A〜D、参照ノートの関連箇所を一括抽出する。同じノートは1回のprepare内で一度だけ読み、次のprepareでは読み直す。Sourceは `学んだこと/` 内の既存Markdownに限定し、外部URL・範囲外リンク・外へ出るシンボリックリンクは停止する。未選択とE選択は先に `unknown` とする。それ以外の `result` と全問の `correct_answer` は `REVIEW`、A〜D解説は `DRAFT:` で始まる下書きになる。

## 2. AIが意味判断を完成させる

全問について次を埋める。

- `correct_answer`: `A`〜`D`の正解記号
- `result`: 選択が正解なら `correct`、A〜Dの誤答なら `incorrect`、Eまたは未選択なら `unknown`
- `explanations`: `incorrect` または `unknown` のとき、A〜Dをすべて完成させる

解説は、同じ要素内の `card_point` と `source_excerpt` を参照し、各選択肢について用語の意味・本来の役割や利用場面・正解肢との具体的な差を書く。選択肢本文の言い換えや定型文だけにしない。正答では解説欄を利用しないため、下書きのままでよい。

JSONの主要部分は次の形になる。

```json
{
  "session_file": "学習記録/復習問題/YYYY-MM-DD.md",
  "session": 1,
  "graded_on": "YYYY-MM-DD",
  "questions": [
    {
      "q": 1,
      "selected": "B",
      "result": "incorrect",
      "correct_answer": "A",
      "explanations": {
        "A": "用語の定義・役割・この設問で正解となる理由",
        "B": "用語の定義・役割・Aとの具体的な差",
        "C": "用語の定義・役割・Aとの具体的な差",
        "D": "用語の定義・役割・Aとの具体的な差"
      }
    }
  ]
}
```

`prepare` が出力した補助フィールドは削除せず、そのまま残してよい。Q番号を抜いたり、同じQ番号を重複させたりしない。

## 3. 一括検証して適用する

```bash
python3 skills/a1-adaptive-review/scripts/grade_review_session.py apply \
  /tmp/a1-grade-YYYY-MM-DD-session-N.json --dry-run

python3 skills/a1-adaptive-review/scripts/grade_review_session.py apply \
  /tmp/a1-grade-YYYY-MM-DD-session-N.json
```

`apply` は次を一括で行う。

1. Question Count、Q連番、0または1個の選択、全Qのマニフェスト入力、正誤整合を検査する。
2. 各問題の直後へ採点欄を挿入し、Sessionヘッダと監査内訳を更新する。
3. カード一覧の `Last Reviewed`、`Next Review`、`Stage`、`Last Result` を更新する。
4. 不正解・不明だけを採点日の `学習記録/間違えた問題/YYYY-MM-DD.md` にA〜D全解説付きで追記する。
5. `verify_review_sessions.py` を実行し、失敗したら変更をロールバックする。

一括適用後も、結果のMarkdown形式は [採点・誤答形式](採点・誤答形式.md) を正とする。

## 検証範囲と下書きの有効性

prepare と apply は同じSession構造を検証する。件数が正の整数で実数と一致し、Q番号が連続、A〜Eが順に一つずつ、Eが `わかりません`、問題文・Card ID・Stageが存在することを要求する。複数選択・重複Session番号も停止する。

prepare は `session_sha256` を付ける。下書き生成後に問題・選択・Stageなどを編集したら、古いJSONの適用は止まる。再prepareし、全問を見直す。このフィールドを削除して回避しない。互換性のため旧来のハッシュなしJSONは受け付けるが、構造は同様に検査する。ハッシュは改変防止署名ではない。

`apply --dry-run` は対象Sessionと更新内容の入力検証を行い、学習ファイルを書き換えない。リポジトリ全体の監査ではない。実applyは従来どおり更新後に全Session監査を行い、失敗時は3ファイルを戻す。全体を変更せず監査するときは `python3 skills/a1-adaptive-review/scripts/verify_review_sessions.py` を実行する。

JSONは `/tmp` に置き、コミットしない。処理完了後に作業用ファイルを削除する。

## 日付移動済みコメントの清掃

過去に別日の誤答記録をHTMLコメント化して残した場合は、次で残骸を削除する。

```bash
python3 skills/a1-adaptive-review/scripts/grade_review_session.py cleanup-moved-comments --dry-run
python3 skills/a1-adaptive-review/scripts/grade_review_session.py cleanup-moved-comments
```

誤答記録はコメントで複製せず、採点日のファイルだけに実体を置く。

## 保存前の整合性と同時実行

- 新しい下書きは `card_sha256` も保持する。対象カードの要点・Source・状態が変わったら再prepareして見直す。無関係なカードの追加では無効にしない。ハッシュなしの旧JSONでも、Card IDの存在・一意性、出題時Stageと現在Stageの一致、採点日の逆行禁止は検査する。
- `session` と `q` は正の整数とする。旧来の数字文字列は受け付けるが、小数・真偽値は拒否する。重複JSONキー、選択状態やCard IDの食い違いも停止する。解説はA〜Dそれぞれ1行の文字列で保存する。
- Sessionは `学習記録/復習問題/` 内のMarkdownに限定する。`prepare --output` はリポジトリ外を指定し、権限600で作る。問題ファイルやカード一覧を下書きで上書きしない。
- 実applyとコメント清掃は、同じ作業コピーの `.a1-grading.lock` で同時書き込みを拒否する。dry-runはロックも学習ファイルも書かない。手編集・別の作業コピーとの排他は保証しない。
- ロックが残ったら、別の採点処理が動いていないこととファイルの状態を確認してから削除する。動作中のロックを自動解除しない。通常のエラー・割込みではロックを解除し、採点の更新は元のバイト列へ戻す。強制終了や停電まで含む複数ファイルの完全なトランザクションではない。
- 誤答記録は「元ファイル・Session番号・Q番号・Card ID」で識別する。別日で同じSession/Q番号でも共存でき、同じ元問題の二重記録だけを拒否する。Source SessionにはSessionへのアンカーを付ける。

全体監査は `verify_review_sessions.py --root <リポジトリ>` でも実行できる。誤答記録の問題文・Your Answer・Correct Answer・模範解答と元Sessionの食い違いも検出する。検査エラーを消すために、過去の回答や正解を勝手に書き換えない。
