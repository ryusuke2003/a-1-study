# 出題手順

## 候補の選択

明示依頼時だけ出題する。既定20問は上限ではない。リポジトリ直下で次を実行し、候補を選んでから問題を作る。

```bash
python3 skills/a1-adaptive-review/scripts/select_review_cards.py --count 20 --format json
```

`--on YYYY-MM-DD` で選出日を固定できる。省略時はJST午前5時切替。`--root` で別のリポジトリを指定する。カード表だけ差し替える `--cards` には、対応する履歴ディレクトリを `--sessions` で必ず併記する。

### 除外・配分・補充

スクリプトは全日付の `学習記録/復習問題/*.md` を読み、`awaiting_answers` の全Card IDを**配分前に除外**する。チェック済みでも未採点なら除外し、`graded` になれば解除する。履歴ディレクトリ欠落や不正なSession構造はエラーにし、未採点なしと見なして続行しない。

残りを次の順で一つの枠だけに分類する。`near_days` は既定3日で、`--near-days N`（0以上）で変更できる。3日は運用設定であり、最適な記憶間隔を証明する値ではない。

| 枠 | 対象 | 目標 |
|---|---|---:|
| `deadline` | `Next Review <= 選出日`。誤答・未復習でも期限到来ならここ | 70% |
| `weak` | 期限未到来、直近 `incorrect/unknown`、期限が `選出日 + near_days` 以内 | 20% |
| `new_or_upcoming` | 上の枠に属さない `unreviewed`、または期間内の `correct` | 10% |

**70/20/10は排他的な選出枠の配分であり、誤答カード全体を20%に制限するものではない。** 期限枠にも誤答や未復習は含まれる。`quotas` は目標、`actual_buckets` は補充後の実数、`selected_traits` は期限到来・誤答/不明・未復習という重複し得る性質の件数である。性質の合計は設問数を超えることがある。

指定数と対象カード数の小さい方に対し、整数の最大剰余法で配分する。候補が十分なら20問は14/4/2、50問は35/10/5となる。枠内は期限、直近評価、最終復習日の古さ、Card IDの順。未復習・近日期限枠では未復習を先にする。

枠不足は対象期間内の未選出カードから期限・評価順に補充し、元の枠を保持して `selection_reason: backfill` と記録する。`backfilled_count` で補充数を示す。補充により比率が変わることを隠さず、未採点カードや期間外の復習カードで穴埋めしない。未復習は将来の期限でも新規学習候補にできる。期間外の復習カードは `deferred_future_ids` に出す。

対象が足りなければ `shortfall` を伝え、重複や無関係な知識で指定数を埋めない。全件未採点やカード0件では0問の結果を返し、`pending_sessions` の既存Sessionや学びの登録を案内する。未採点除外IDは `excluded_pending_ids` で確認できる。

分野の並べ替えは選出集合を変えない。候補の `Source` ノートと直近Sessionを読んで問い方を確認する。選出中に別Sessionが追加された可能性があれば保存前に再選出する。この処理は読み取り専用で、同時実行間の予約ロックではない。

特定テーマでは通常比率を使わず核と周辺をまとめてよいが、未採点との重複禁止は維持する。明示的な重複練習は通常フローと分け、既存Sessionへの案内を優先する。周辺は混同概念・前提/例外・役割/主体/入出力/手順・判断に必要な基礎に限定し、`related-reinforcement` は元カードを `Related To` に残す。

## 問い方と選択肢

[問題・採点形式](問題・採点形式.md) のMarkdownを使う。回答前の正解や解説は保存しない。

- 初回は定義・役割を確認する。再出題は登録範囲内で、比較、成立条件、短い事例への適用などに視点を変える。正解位置だけを変えた同一問題を反復しない。
- 問われる主体・範囲・条件を明記する。各A〜Dが同じ種類・個数の対象に答えるようにする。4概念を問うなら全選択肢が4概念を扱う。
- 誤答は実際に混同しやすい説明にする。無関係な用語、誤答にだけ付く「必ず」「だけ」、正解だけが長い・具体的といった形式上の手掛かりを避ける。文字数合わせ自体を目的にしない。
- 配置前に設問を解き直し、A〜Dの各肢がなぜ正しい／誤りかを検討して正解が一つだけか確かめる。ノートに根拠が足りなければ要確認とし、推測で採点可能な問題にしない。

実例の監査観点：2026-09-06 Session 1 Q6は正解だけが4概念を詳述し、他肢は2概念または無関係な記述だった。以後は説明する対象と情報量をそろえる。過去の回答済み問題は書き換えない。

## 正解位置と出題前チェック

A〜Dの正解位置を均等に配ってシャッフルする。Eは常に `わかりません`。並びを学習者に見せず、固定のABCD反復や毎回同じseedを使わない。

```bash
python3 skills/a1-adaptive-review/scripts/prepare_review.py answer-slots \
  --count 20 > /tmp/a1-answer-slots.json
```

これは正解の内容を生成・検証するものではなく、配置だけの補助である。20問なら各5回、それ以外も最多と最少の差は1以下になる。配置後に正解内容をもう一度確認する。

```bash
python3 skills/a1-adaptive-review/scripts/prepare_review.py check \
  学習記録/復習問題/YYYY-MM-DD.md --session N
```

`check` は読み取り専用で、件数・連番、必要項目、A〜Eの重複／欠落、Eの文言、同一カードの重複、事前チェック、代表的な正解・採点欄の混入を検出する。知識の正確さ、複数正解、自然文のヒントまでは検証できない。合格しても上の意味チェックを省略しない。配置表は使用後に削除する。

## 明示された短期集中計画

問題作成依頼があった日に限り、1か月目は20問中の新規過去問を10〜12問までとし、残りを期限に沿う復習にする。2か月目は新規を穴埋め中心にし、毎日20問の復習、本番形式30問・50分を週2回の目安とする。選択肢を無差別にカード化せず、周辺整理が復習を圧迫したら後回しにする。これは希望に応じた計画であり、通常の復習への強制枠ではない。
