# 学びの登録・整理

1. 自由文を、用語・定義・比較・条件・因果・手順に分ける。
2. 主分野を決める。必要なら関連分野も記録する。
3. 既存ノートと同じ内容なら統合し、異なる観点は追記する。
4. 核となる知識を一枚の復習カードにする。
5. 次のどれかに該当する直接周辺知識を、必要な分だけ追加でカード化する。
   - 同じ問題の誤答選択肢、対になる概念、混同しやすい概念
   - 成立条件・前提・例外
   - 仕組みの役割、主体、入力・出力、手順の前後関係
   - 正解を判断するために必要な頻出の基礎事項
6. 周辺カードと核カードの関連は、`Source` ノート内に `Related To: A1-xxxx` と理由を記録する。カード一覧は既存の8列を維持し、存在しない補足列やカード本文ファイルを作らない。出題時はSessionの `Related To` に転記する。
7. 不確かな記述や質問は `要確認` として保存し、事実として問題化しない。

一つの問題やテーマから、核1個と周辺2〜6個程度を目安に回収する。ただし数を満たすためだけの追加はしない。登録しても問題Sessionは作らない。

カードの要点・状態は `復習カード/カード一覧.md` の該当行だけを更新する。未採点の `Last Reviewed` は `-` とする。採点に伴う状態更新は専用スクリプトに任せる。ノートや履歴を全件読み込まず、対象分野・カードIDで必要箇所を参照する。
