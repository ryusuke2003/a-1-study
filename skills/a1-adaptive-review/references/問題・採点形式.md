# 問題・採点形式

## 出題 Session

問題作成時は、回答前に正解を表示しない。各問題は一つだけチェックする。

```markdown
# YYYY-MM-DD 復習問題

## Session N

- Created: YYYY-MM-DD
- Status: awaiting_answers
- Mode: spaced-review
- Question Count: 5

### Q1

- Domain: <主分野>
- Card ID: <カードID>
- Source: [<ノート名>](<学んだことのノートへのリンク>)
- Type: <registered|related-reinforcement>
- Related To: <補強問題の場合は元カードID>
- Stage: <0-5+>

### 問題

<問題文>

- [ ] A. <知識選択肢>
- [ ] B. <知識選択肢>
- [ ] C. <知識選択肢>
- [ ] D. <知識選択肢>
- [ ] E. わかりません
```

`Type: related-reinforcement` の場合は、`Related To` に出題の起点となった登録カードを必ず記録する。

正解、解説、採点結果は回答前に正本となるMarkdownへ保存しない。学習者が回答した後、[採点マニフェスト](採点マニフェスト.md) の一括処理で、同じSessionの**各問題の選択肢の直後**へ追記する。集計用の別節は作らない。不正解・不明の問題に限り、採点後に `学習記録/間違えた問題/YYYY-MM-DD.md` へ復習用の控えを保存する。

## 選択肢

- A〜D のうち、設問をすべて満たす正解は一つだけにする。
- 誤答肢は、近い役割の仕組み、条件不足の対策、主体・範囲・順序の取り違えを使う。
- 無関係で明白な誤答、複数正解に読める表現、設問にない前提を要求する表現を避ける。
- E は常に `わかりません` とする。正答肢にはしない。

出題前は [出題手順](出題手順.md) の品質確認と `prepare_review.py check` を行う。採点後の構造は [採点・誤答形式](採点・誤答形式.md) を参照する。出題だけの作業では採点後の形式を読み込まない。
