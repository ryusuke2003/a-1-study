# 問題・採点形式

## 出題 Session

問題作成時は、回答前に正解を表示しない。各問題は一つだけチェックする。

```markdown
# YYYY-MM-DD 復習問題

## Session N

- Created: YYYY-MM-DD
- Status: awaiting_answers
- Mode: spaced-review
- Question Count: 5

### Q1

- Domain: <主分野>
- Card ID: <カードID>
- Source: [<ノート名>](<学んだことのノートへのリンク>)
- Type: <registered|related-reinforcement>
- Related To: <補強問題の場合は元カードID>
- Stage: <0-5+>

### 問題

<問題文>

- [ ] A. <知識選択肢>
- [ ] B. <知識選択肢>
- [ ] C. <知識選択肢>
- [ ] D. <知識選択肢>
- [ ] E. わかりません
```

`Type: related-reinforcement` の場合は、`Related To` に出題の起点となった登録カードを必ず記録する。

正解、解説、採点結果は回答前に別ファイルへ保存しない。学習者が回答した後、同じSessionの**各問題の選択肢の直後**へ追記する。集計用の別節は作らない。不正解・不明の問題に限り、採点後に `学習記録/間違った問題/YYYY-MM-DD.md` へ復習用の控えを保存する。

## 選択肢

- A〜D のうち、設問をすべて満たす正解は一つだけにする。
- 誤答肢は、近い役割の仕組み、条件不足の対策、主体・範囲・順序の取り違えを使う。
- 無関係で明白な誤答、複数正解に読める表現、設問にない前提を要求する表現を避ける。
- E は常に `わかりません` とする。正答肢にはしない。

## 採点追記

回答後に、各問題へ次を追記する。

```markdown
### 採点

Score: <100|0> / 100
Result: <correct|incorrect|unknown>
Next Review: YYYY-MM-DD
```

通常の問題Sessionの採点欄には、正誤・不明を問わず `#### 解説` を付けない。解説は不正解・不明の「間違った問題」記録にだけ保存する。

採点欄は必ず、その問題の選択肢と次の `### Qn` 見出しの間に置く。最終問では選択肢の直後に置く。追記後、各問題に `### 採点` が一つだけあり、問題番号と採点結果がずれていないことを確認する。

## Session完了監査

採点は回答済みの設問だけを抜き出して処理しない。対象Sessionの全設問を採点し、最後にヘッダを次のように更新する。

```markdown
- Status: graded
- Graded: YYYY-MM-DD
- Grading Audit: questions=<n>, graded=<n>, correct=<n>, incorrect=<n>, unknown=<n>
```

`Question Count`、実際のQ見出し数、採点欄数はいずれも `questions` と一致させる。Q番号は `Q1` から連番とする。各問の選択済みは0または1個とし、0個は未選択の `unknown`、複数選択は不正として扱う。不一致、欠番、重複、採点欄の位置ずれがあれば、先にSession構造を直してから採点する。

問題数に上限はない。20問は出題時の既定値にすぎず、30問・49問以上でも、対象Sessionの全問を同じ監査単位として採点する。作業を分割しても、全問数と `graded` が一致するまでSessionを完了にしない。

採点結果はカードの `Last Reviewed`、`Next Review`、`Stage`、`Last Result` にも反映する。同じカードを再復習した場合、カード一覧の現在値と照合するのはそのカードの最新採点だけとし、過去の採点欄は当時の履歴として保持する。E、未選択、複数選択の `Result` は `unknown`、それ以外の誤答は `incorrect` とする。

## 間違った問題の記録

不正解または `unknown` の問題だけを、採点日ごとに `学習記録/間違った問題/YYYY-MM-DD.md` に追記する。

```markdown
# YYYY-MM-DD 間違った問題

## Session <元のSession番号> / Q<元の問題番号>: <Card ID>

- Source Session: <元の問題ファイルを一意に特定するリンク>
- Your Answer: <学習者が選んだ選択肢>
- Correct Answer: <正解の選択肢>

### 問題

<問題文>

### 模範解答

<正解の選択肢を、選択肢記号と本文で記載する>

### 解説

- A: <元の選択肢Aの本文>
  → <選択肢Aの用語の定義・本来の役割・この設問で正誤となる具体的理由>
- B: <元の選択肢Bの本文>
  → <選択肢Bの用語の定義・本来の役割・この設問で正誤となる具体的理由>
- C: <元の選択肢Cの本文>
  → <選択肢Cの用語の定義・本来の役割・この設問で正誤となる具体的理由>
- D: <元の選択肢Dの本文>
  → <選択肢Dの用語の定義・本来の役割・この設問で正誤となる具体的理由>

<正解となる仕組み・条件と各選択肢との差を、上の選択肢別説明で具体的に示す。カード要点の転載や一般論だけで終えない。>
```

各 `- A:`〜`- D:` 行には元の問題Sessionの選択肢本文をそのまま載せ、その直下の `→` 行に解説を置く。解説を選択肢本文の再掲だけにしたり、`この用語が表す役割・概念です`、`設問の条件には合わない`、`正解とは区別する`、`正解の選択肢です` のような定型文だけにしたりしてはならない。

この「問題」「模範解答」「解説」は、不正解・不明の記録には必須であり、この順で記載する。一方、正答を含む通常の問題Sessionの採点欄には原則として解説を付けない。
