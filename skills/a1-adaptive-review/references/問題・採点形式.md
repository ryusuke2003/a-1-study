# 問題・採点形式

## 出題 Session

問題作成時は、回答前に正解を表示しない。各問題は一つだけチェックする。

```markdown
# YYYY-MM-DD 復習問題

## Session N

- Created: YYYY-MM-DD
- Status: awaiting_answers
- Mode: spaced-review
- Question Count: 5

### Q1

- Domain: <主分野>
- Card ID: <カードID>
- Source: [<ノート名>](<学んだことのノートへのリンク>)
- Type: <registered|related-reinforcement>
- Related To: <補強問題の場合は元カードID>
- Stage: <0-5+>

### 問題

<問題文>

- [ ] A. <知識選択肢>
- [ ] B. <知識選択肢>
- [ ] C. <知識選択肢>
- [ ] D. <知識選択肢>
- [ ] E. わかりません
```

`Type: related-reinforcement` の場合は、`Related To` に出題の起点となった登録カードを必ず記録する。

正解、解説、採点結果は回答前に別ファイルへ保存しない。学習者が回答した後、同じSessionの**各問題の選択肢の直後**へ追記する。集計用の別節は作らない。不正解・不明の問題に限り、採点後に `学習記録/間違った問題/YYYY-MM-DD.md` へ復習用の控えを保存する。

## 選択肢

- A〜D のうち、設問をすべて満たす正解は一つだけにする。
- 誤答肢は、近い役割の仕組み、条件不足の対策、主体・範囲・順序の取り違えを使う。
- 無関係で明白な誤答、複数正解に読める表現、設問にない前提を要求する表現を避ける。
- E は常に `わかりません` とする。正答肢にはしない。

## 採点追記

回答後に、各問題へ次を追記する。

```markdown
### 採点

Score: <100|0> / 100
Result: <correct|incorrect|unknown>
Next Review: YYYY-MM-DD

#### 解説

<正解と、誤答なら取り違えた要点を一〜三文で説明する>
```

採点欄は必ず、その問題の選択肢と次の `### Qn` 見出しの間に置く。最終問では選択肢の直後に置く。追記後、各問題に `### 採点` が一つだけあり、問題番号と採点結果がずれていないことを確認する。

採点結果はカードの `Last Reviewed`、`Next Review`、`Stage`、`Last Result` にも反映する。E、未選択、複数選択の `Result` は `unknown`、それ以外の誤答は `incorrect` とする。

## 間違った問題の記録

不正解または `unknown` の問題だけを、採点日ごとに `学習記録/間違った問題/YYYY-MM-DD.md` に追記する。

```markdown
# YYYY-MM-DD 間違った問題

## Q<元の問題番号>: <Card ID>

- Source Session: <元の問題ファイルへのリンク>
- Your Answer: <学習者が選んだ選択肢>
- Correct Answer: <正解の選択肢>

### 問題

<問題文>

### 解説

<正解と混同しやすい点>
```
