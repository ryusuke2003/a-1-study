# A-1 適応復習

他教材で学んだ内容の整理と想起練習を支援する。試験範囲を先回りして網羅的に教えない。

## 共通ルール

- 問題は学習者が明示的に依頼したときだけ作る。登録・整理・採点・状況確認から自動出題しない。
- 登録内容と正解判定に直接必要な周辺知識だけ扱う。実装詳細・発展的派生・例外網羅は避け、`要確認` は出題しない。
- Markdownを正本とする。カードの要点・状態は `復習カード/カード一覧.md`、詳説は `Source` の `学んだこと/`、出題・採点履歴は `学習記録/復習問題/` に置く。カード本文を複製しない。
- `過去問/` は開催回別の参照用コピー。過去問由来の登録は [登録・整理](references/登録・整理.md) に従い、`学んだこと/` の解説を同期する。
- JST午前5時に学習日を切り替える。00:00〜04:59は前日の学習日とする。
- 採点更新は専用スクリプトだけで行う。作業用JSON・正解配置表は `/tmp` に置き、公開・コミットしない。pushは明示依頼時だけ行う。
- Gitコミットメッセージは日本語で書く。

## 作業別に読む文書

該当する行だけ読む。複合依頼では必要な行を組み合わせる。通常操作ではスクリプトのソース全文を読まず、改修・障害調査時だけ読む。

| 作業 | 必須の参照 | 処理 |
|---|---|---|
| 登録・整理 | [登録・整理](references/登録・整理.md) | ノートとカードを更新。過去問由来なら解説も同期。出題しない |
| 問題作成 | [出題手順](references/出題手順.md)、[問題・採点形式](references/問題・採点形式.md) | `select_review_cards.py` で候補選出 → 出題前チェック。既定20問 |
| 採点 | [採点マニフェスト](references/採点マニフェスト.md)、[採点・誤答形式](references/採点・誤答形式.md) | prepare → 全問判断 → dry-run → apply |
| 状況確認 | 追加参照なし | `study_status.py` で期限・未採点・分野別件数を集計。出題しない |

カードがなければ登録を案内する。文書・ノート・過去Sessionを無条件に全部読まず、対象のカード・分野・Sessionに絞る。
